# MVP 기능 명세

## Phase 구분

### Phase 1 — 핵심 주문 루프 (4~6주)

최소한의 기능으로 "손님이 주문 → 주방에서 수신 + 출력" 루프를 완성합니다.

#### 손님용 앱

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 시작 화면 | 가게 로고 + "주문하기" 버튼 | P0 |
| 메뉴 목록 | 카테고리별 메뉴 카드 그리드 | P0 |
| 메뉴 상세 | 사진 + 설명 + 옵션 선택 + 수량 | P0 |
| 장바구니 | 항목 리스트 + 수량 변경 + 합계 | P0 |
| 주문 확인 | 최종 내역 확인 + 주문 전송 | P0 |
| 주문 완료 | 주문번호 표시 + 추가 주문 | P0 |
| 직원 호출 | 모든 화면 하단 고정 버튼 | P0 |
| 자동 복귀 | 2분 미터치 시 시작 화면 | P1 |
| 키오스크 잠금 | 시스템 UI 차단 | P1 |

#### POS 앱

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 주문 대시보드 | 테이블별 주문 카드 표시 | P0 |
| 실시간 수신 | WebSocket으로 신규 주문 즉시 반영 | P0 |
| 알림음 | 새 주문 시 소리 알림 | P0 |
| 영수증 출력 | 주문 접수 시 프린터 자동 출력 | P0 |
| 직원 호출 수신 | 토스트 알림 (자동 소멸) | P1 |

#### 백엔드

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 메뉴 API | CRUD + 품절 토글 | P0 |
| 주문 API | 주문 생성 + 조회 | P0 |
| WebSocket | POS로 실시간 주문 푸시 | P0 |
| 테이블 API | 등록 + 조회 | P0 |

#### 관리자 페이지

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 메뉴 관리 | 추가 / 수정 / 삭제 / 사진 업로드 | P0 |
| 카테고리 관리 | 추가 / 수정 / 순서 변경 | P0 |
| 품절 처리 | 토글 (전 태블릿 즉시 반영) | P0 |
| 테이블 관리 | 등록 / 삭제 | P1 |

### Phase 2 — 결제 + 운영 (3~4주)

#### 결제

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 전체 결제 | 테이블 전체 금액 일괄 처리 | P0 |
| 결제 수단 기록 | 카드/현금/QR/상품권/기타 선택 | P0 |
| 분할 결제 (N분의1) | 균등 분할, 건별 수단 선택 | P1 |
| 분할 결제 (항목별) | 메뉴별 배분 | P2 |
| 복합 결제 | 수단 혼합 (상품권+카드 등) | P1 |
| 결제 완료 처리 | 영수증 출력 + 테이블 초기화 + 태블릿 복귀 | P0 |
| 현금 거스름돈 | 받은 금액 입력 → 거스름돈 계산 | P1 |

**MVP 결제 방식**: 실제 PG 연동 없이 결제 내역만 기록. 실 결제는 기존 단말기에서 처리 후 POS 앱에서 수동 확인.

#### 매출

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 일별 매출 | 날짜별 합계 | P0 |
| 월별 매출 | 월별 합계 + 추이 | P1 |
| 메뉴별 순위 | 판매량 기준 정렬 | P1 |
| 결제 수단별 | 수단별 비율 | P2 |
| 주문 이력 | 날짜/테이블 검색 | P1 |

### Phase 3 — 확장 (선택)

| 기능 | 설명 |
|------|------|
| PG 연동 | 실제 카드/QR 결제 자동 처리 |
| QR 스캔 결제 | 바코드 리더기 → PG API 연동 |
| 메뉴 옵션 고도화 | 필수/선택 옵션, 추가 금액 |
| 다국어 메뉴 | 영어/중국어/일본어 |
| 테이블 QR | 손님 스마트폰으로도 주문 가능 |
| POS 연동 | 기존 POS에 주문 데이터 전송 |

## 하드웨어 요구사항

### 필수

| 장비 | 수량 | 용도 |
|------|------|------|
| Android 태블릿 (10인치+) | 테이블 수만큼 (16+) | 손님 주문 |
| Windows PC | 1대 (기존 POS PC 활용) | 서버 + POS 앱 + 프린트 서버 |
| 영수증 프린터 (USB) | 1대 (기존 활용 가능) | 주방 영수증 출력 |
| Wi-Fi 공유기 | 1대 | 내부 네트워크 |

### Phase 2+

| 장비 | 수량 | 용도 |
|------|------|------|
| 바코드/QR 리더기 (USB) | 1대 | QR 결제 스캔 |

## 우선순위 기준

- **P0**: 이것 없으면 시스템이 작동하지 않음
- **P1**: 운영에 필요하지만 첫 출시 후 추가 가능
- **P2**: 있으면 좋지만 없어도 운영 가능
