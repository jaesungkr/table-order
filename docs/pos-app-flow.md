# POS 앱 화면 플로우

## 플랫폼

- Windows PC (기존 POS PC 활용)
- Python + pywebview (Slink과 동일 아키텍처)

## 메인 대시보드

### 주문 카드

- 테이블 번호 (크게 표시)
- 주문 항목 목록
- 접수 시간
- 누적 금액 (추가 주문 포함)
- "결제" 버튼

### 실시간 수신

- WebSocket으로 백엔드 서버와 연결
- 새 주문 수신 시:
  - 알림음 재생
  - 주문 카드 하이라이트
  - 영수증 프린터 자동 출력
- 추가 주문 시 기존 카드에 항목 추가

### 직원 호출 알림

- 손님 태블릿에서 호출 시 토스트 형태로 표시
- 알림음 재생
- 테이블 번호 + 호출 시간 표시
- 일정 시간(5~10초) 후 자동 소멸
- 별도 확인 처리 불필요

## 결제 화면

테이블 카드에서 "결제" 선택 시 진입.

### 결제 방식 (3종)

#### 전체 결제

한 사람이 전체 금액을 한번에 결제.

```
주문 합계: 45,000원
결제 수단 선택 → 결제 완료
```

#### 분할 결제 (더치페이)

두 가지 모드 지원:

**N분의1**: 총 금액 ÷ 인원수로 균등 분할. 각 건마다 결제 수단을 따로 선택 가능.

```
주문 합계: 45,000원 ÷ 3명 = 15,000원씩
1번: 카드 15,000원 ✓
2번: 현금 15,000원 ✓
3번: QR 15,000원 ← 진행 중
```

**항목별**: 각 메뉴를 누가 먹었는지 선택해서 개별 금액 산출.

```
김치찌개 9,000원 → A
된장찌개 8,000원 → B
공기밥 x3 3,000원 → 공동
```

#### 복합 결제

한 건에서 결제 수단을 섞는 경우.

```
주문 합계: 45,000원
1차: 상품권 20,000원 → 잔액 25,000원
2차: 카드 25,000원 → 완료
```

### 결제 수단 (5종)

| 수단 | 설명 | MVP 처리 방식 |
|------|------|---------------|
| 카드 | 카드 결제 | 기존 단말기에서 처리 후 POS 앱에서 확인 |
| 현금 | 현금 수령 | 금액 입력 후 거스름돈 계산 |
| QR 스캔 | 네이버페이, 카카오페이 등 | 바코드 리더기로 손님 QR 스캔 → PG 승인 |
| 상품권 | 금액권 차감 | 권종 선택 + 잔액 처리 |
| 기타 | 쿠폰, 포인트 등 | 확장용 슬롯 |

### QR 스캔 결제 상세

1. POS에서 "QR 스캔" 선택 + 금액 확인
2. 손님이 네이버페이/카카오페이 등에서 바코드 화면 제시
3. POS PC에 USB 연결된 바코드 리더기로 스캔
4. 리더기가 바코드 값을 키보드 입력으로 전달
5. POS 앱이 바코드 값 수신 → PG API에 결제 요청
6. 승인 결과 수신 → 결제 완료

**하드웨어 요구**: 바코드/QR 리더기 (USB, POS PC에 연결)

**MVP 참고**: PG 연동은 Phase 2. MVP에서는 기존 단말기에서 QR 결제 후 POS 앱에서 수동 확인.

### 결제 완료 시 동작

1. 영수증 출력
2. 해당 테이블 주문 내역 아카이브
3. 매출 데이터 기록
4. 손님 태블릿에 시작 화면 복귀 신호 전송
5. 대시보드에서 테이블 카드 제거

## 관리 기능 (사이드 메뉴)

### 메뉴 관리

- 메뉴 추가 / 수정 / 삭제
- 사진 업로드
- 카테고리 관리
- 품절 토글 (즉시 전 태블릿 반영)
- 옵션 그룹 관리 (맵기, 사이즈 등)

### 테이블 관리

- 테이블 등록 / 삭제
- 테이블 번호 변경
- 현재 상태 확인 (주문 중 / 비어있음)

### 매출 조회

- 일별 / 월별 매출 집계
- 메뉴별 판매 순위
- 결제 수단별 비율
- 주문 이력 검색
