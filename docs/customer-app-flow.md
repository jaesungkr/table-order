# 손님용 앱 화면 플로우

## 플랫폼

- Android 태블릿 (Kotlin)
- 키오스크 모드 고정

## 화면 흐름

```
시작 화면
    │
    │ "주문하기" 터치
    ▼
메뉴 목록
    │
    │ 메뉴 카드 터치
    ▼
메뉴 상세
    │
    │ "장바구니 담기"
    ▼
장바구니
    │
    │ "주문하기"
    ▼
주문 확인
    │
    │ "주문 전송"
    ▼
주문 완료 ──────▶ 메뉴 목록 (추가 주문)
    │
    │ 2분 미터치
    ▼
시작 화면 (자동 복귀)
```

## 화면별 상세

### 1. 시작 화면

- 가게 로고 + 가게 이름
- "주문하기" 버튼 (크고 눈에 띄게)
- 테이블 번호 표시 (변경은 비밀번호 필요)
- 전체 화면에서 2분 미터치 시 자동 복귀 대상

### 2. 메뉴 목록

- 상단: 카테고리 탭 (전체, 식사, 사이드, 음료 등)
- 본문: 메뉴 카드 그리드 (사진 + 이름 + 가격)
- 품절 메뉴: 흐리게 표시, 터치 불가
- 하단: 장바구니 미리보기 바 (담은 수량 + 합계 + "장바구니 보기")

### 3. 메뉴 상세

- 큰 메뉴 사진
- 메뉴 이름 + 가격
- 설명 텍스트
- 옵션 선택 (맵기 조절, 사이즈, 토핑 추가 등)
- 수량 조절 (+/-)
- "장바구니 담기" 버튼

### 4. 장바구니

- 담은 메뉴 리스트 (이름, 옵션, 가격)
- 개별 수량 변경 (+/-) 및 삭제
- 합계 금액 표시
- "더 담기" 버튼 → 메뉴 목록으로
- "주문하기" 버튼 → 주문 확인으로

### 5. 주문 확인

- 최종 주문 내역 요약
- 테이블 번호 표시
- 합계 금액
- "주문 전송" 버튼 (실수 방지용 마지막 관문)
- "뒤로" 버튼 → 장바구니로

### 6. 주문 완료

- 주문번호 표시
- "추가 주문" 버튼 → 메뉴 목록으로
- 2분 미터치 시 시작 화면으로 자동 복귀
- 결제 완료 신호 수신 시에도 시작 화면 복귀

## 공통 요소

### 직원 호출 버튼

- 모든 화면 하단에 고정
- 터치 시 POS에 토스트 알림 전송 (알림음 + 테이블 번호)
- 연속 호출 방지: 호출 후 30초간 비활성화

### 자동 복귀

- 모든 화면에서 2분간 터치 없으면 시작 화면으로 복귀
- 장바구니 내용은 복귀 시 초기화

### 키오스크 모드

- Android 키오스크 모드 (COSU)로 잠금
- 홈 버튼, 뒤로 가기, 상태바 접근 차단
- 설정 화면 접근: 시작 화면에서 특정 영역 길게 터치 → 비밀번호 입력
- 설정에서 변경 가능: 테이블 번호, 서버 IP, 자동 복귀 시간
