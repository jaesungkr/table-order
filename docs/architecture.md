## 컴포넌트별 역할

### 손님용 Android 태블릿 앱

- 테이블마다 1대 고정 설치
- 키오스크 모드로 잠금 (홈 버튼, 상태바 차단)
- 메뉴 탐색 → 장바구니 → 주문 전송
- 2분 미터치 시 자동으로 시작 화면 복귀
- 테이블 번호는 최초 설정 시 지정 (설정 화면은 비밀번호 잠금)

### POS/주방 수신 Windows 앱

- Slink과 동일한 아키텍처: pywebview(frameless, WebView2) + 로컬 HTTP API
- 실시간 주문 수신 (WebSocket)
- 주문 접수 시 영수증 프린터 자동 출력
- 소리 알림 (새 주문 시)
- 결제 처리 (전체/분할/복합 결제)
- 직원 호출 수신 (토스트 알림, 자동 소멸)

### 백엔드 서버

- Python FastAPI
- REST API + WebSocket
- 가게 내 PC에서 실행 (인터넷 끊겨도 로컬 네트워크에서 동작)
- PostgreSQL (또는 초기 SQLite로 시작)

### 프린트 서버

- POS PC에서 백그라운드 실행
- 백엔드 서버에서 주문 데이터 수신 → ESC/POS 명령으로 프린터 출력
- USB 연결 영수증 프린터 제어
- python-escpos 라이브러리 사용

### 관리자 웹 페이지

- 백엔드 서버에 내장
- 브라우저로 접속 (PC, 스마트폰)
- 메뉴 CRUD, 품절 처리, 테이블 관리, 매출 조회

## 통신 프로토콜

| 구간 | 프로토콜 | 용도 |
|------|----------|------|
| 태블릿 → 서버 | HTTP (REST) | 메뉴 조회, 주문 전송 |
| 서버 → POS 앱 | WebSocket | 실시간 주문 푸시, 직원 호출 알림 |
| 서버 → 프린트 서버 | HTTP | 주문 데이터 전송 → 영수증 출력 |
| 서버 → 태블릿 | WebSocket | 결제 완료 시 시작 화면 복귀 신호 |
| 관리자 → 서버 | HTTP | 메뉴 관리, 매출 조회 |

## 네트워크 구성

모든 통신은 가게 내부 Wi-Fi 네트워크에서 이루어집니다. 서버는 가게 PC에서 실행되므로 외부 클라우드 의존성이 없습니다. 인터넷이 끊겨도 주문/출력 기능은 정상 동작합니다.

관리자 페이지는 외부 접근이 필요할 경우 포트 포워딩 또는 VPN으로 처리할 수 있지만, MVP에서는 가게 내부 접속만 지원합니다.

## 기존 POS와의 관계

기존 Windows POS는 결제 단말기로만 사용합니다. 주문 접수와 관리는 새 시스템이 전담합니다. 기존 POS와의 데이터 연동은 MVP 범위 밖이며, 추후 POS 브랜드/모델 확인 후 검토합니다.
